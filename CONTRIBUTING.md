# Contributing

Thanks for taking the time to improve this project.

## How to Contribute

1. Fork the repository.
2. Create a new branch:

```bash
git checkout -b feature/short-description
```

3. Make your changes.
4. Run the relevant checks and tests.
5. Open a pull request with a clear description.

## Commit Messages

Use short, descriptive commit messages:

```text
Add login form validation
Fix broken build script
Update installation docs
```

## Pull Request Checklist

- The change has a clear purpose.
- Tests were added or updated when useful.
- Documentation was updated if behavior changed.
- The project still builds and runs locally.

## Reporting Issues

When opening an issue, include:

- What happened
- What you expected to happen
- Steps to reproduce the problem
- Screenshots or logs, if helpful
- Your environment, such as OS, runtime version, and browser
